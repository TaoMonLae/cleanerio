# Security

Cleanerio moves files to the Trash on people's Macs, so mistakes here matter.

Please report privately, not in a public issue, if you find a way to make
Cleanerio:

- remove or offer to remove something outside the locations it is meant to clean,
- follow a link or crafted file name to a place it should not touch,
- run a command with input it should not trust,
- send any data off the Mac.

Use GitHub's private reporting: **Security → Report a vulnerability** on
<https://github.com/TaoMonLae/cleanerio>. Include the macOS version, the
Cleanerio version and the steps to reproduce.

Only the latest release receives fixes.
